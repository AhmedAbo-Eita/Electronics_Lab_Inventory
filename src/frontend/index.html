How to Access the Database in DBeaver / External Tools

1. Local SQLite Database: In DBeaver, select New Connection → SQLite → browse to data/lab_inventory.db. Supports all standard SQL queries.

2. Remote MySQL Database: Enter your MySQL host & port above. The app automatically creates the lab_inventory and inventory_audit_log tables.

3. Quick Query: SELECT mpn, quantity, value, footprint, location FROM lab_inventory;
