Database & Remote Sync

When disabled, all data is stored locally in data/lab_inventory.db (SQLite).
How to Access the Database in DBeaver

1. Local Offline Database (SQLite): In DBeaver, click New Connection → SQLite → browse to data/lab_inventory.db → click Finish. You will see the lab_inventory table with full SQL query support.

2. Remote Online Database (MySQL): In DBeaver, click New Connection → MySQL → enter your MySQL credentials. The app automatically creates and synchronizes the lab_inventory table on both ends.

3. Example SQL Query: SELECT mpn, quantity, value, footprint, location FROM lab_inventory;
